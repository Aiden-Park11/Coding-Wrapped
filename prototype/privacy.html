개인정보 처리방침

시행일 2026-11-24 · Coding Wrapped (KNU CS 2026)
한 줄 요약: Wrapped 카드를 만드는 데 필요한 것만 잠깐 읽고, 2시간 안에 지워요. 데이터베이스에 저장하지 않고, 누구에게도 넘기지 않아요.

1. 어떤 정보를 받나요

출처받는 정보
GitHub
(앱 설치 시 고른 레포만)
  • GitHub 아이디
  • 올해 내 커밋의 시각, 커밋 메시지 첫 줄, 바뀐 파일 이름
  • 레포 이름, 사용 언어 비율, force push 기록
  • 같은 레포에 다른 기여자가 있는지 여부 (그 사람의 아이디는 저장하지 않아요)
코드 내용은 읽지 않아요. 권한은 읽기 전용이에요.
solved.ac
(백준 아이디를 입력한 경우만)
  • 입력한 아이디의 티어, 레이팅, 푼 문제 수, 많이 푼 알고리즘 유형, 최장 스트릭
생일, 이름, 자기소개 같은 다른 프로필 정보는 받더라도 쓰지 않고 바로 버려요.

2. 왜 쓰나요

오직 내 Wrapped 카드(커밋 통계, 개발자 유형, 백준 기록 카드)를 만들어 보여주기 위해서만 써요. 광고, 분석, 학습 데이터로 쓰지 않아요.

3. 얼마나 보관하나요

  • 서버 메모리에만 잠깐 두고, 데이터베이스나 파일에 저장하지 않아요.
  • 로그인 세션은 최대 2시간 뒤 자동으로 지워져요. "내 기록 지우고 나가기"를 누르면 그 즉시 지워요.
  • GitHub 접근 토큰은 분석이 끝나면 바로 버려요.
  • 백준 기록은 조회해서 화면에 보여주기만 하고 서버에 남기지 않아요.
  • 서버가 다시 시작되면 메모리에 있던 정보는 모두 사라져요.

4. 다른 곳에 주나요

주지 않아요. 판매하거나 공유하지 않아요. 서버는 Render(클라우드 호스팅)에서 돌아가며, 정보 처리는 그 서버 안에서만 이뤄져요.

카드 이미지를 저장하거나 공유하는 건 이용자가 직접 할 때만 일어나요.

5. 동의를 철회하려면

  • 마지막 카드의 "내 기록 지우고 나가기"를 누르면 서버에 있던 내 정보가 바로 지워져요.
  • GitHub → Settings → Applications → Installed GitHub Apps에서 KNU Code Wrapped를 제거하면 더 이상 레포를 읽을 수 없어요.
  • 백준 기록은 저장하지 않아서 따로 지울 것이 없어요.

6. 백준 아이디 입력 시 주의

본인 아이디만 입력해 주세요. 다른 사람의 아이디로 조회하는 건 허용하지 않아요.

7. 데이터 출처

백준 기록은 solved.ac 공식 API를 통해 가져와요. 이 서비스는 solved.ac의 공식 서비스가 아니며, solved.ac와 제휴하거나 보증받지 않았어요.

8. 문의

GitHub Issues로 남겨 주세요.
